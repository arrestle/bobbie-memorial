# Barbara "Bobbie" Blackledge Restle: Photo Timeline

The family album photos, arranged in date order and grouped by the sections of her written timeline, [environmentalism/timeline.md](<../../environmentalism/timeline.md>). Each folder here matches one section of that timeline. Inside each folder the photos are numbered oldest to newest.

Everything in this folder is a copy. The original scans, the separated photos and the enhanced versions are unchanged in their own folders (see [Where the originals are](#where-the-originals-are)).

## How to read a file name

`03 - Summer 1942 - Bobbie tending radishes - ....jpg` means: third photo in its section, taken in summer 1942, followed by the description. A `.txt` file with the same name holds the handwritten caption, date stamp or family note for that photo, where there is one.

Each photo uses its **enhanced** version. Where the enhanced version was deleted because it came out grainy, the **original** is used instead. The tables below say which.

## How each date was worked out

| Label | Meaning |
|---|---|
| Caption | Written on the album page or on the photo itself. |
| Lab stamp | Printed on the border by the photo lab. This is when the film was developed, so the picture was taken then or shortly before. |
| Newspaper | From a dated newspaper clipping. |
| Camera date | Recorded by the phone that took the picture, in the photo file itself. |
| Family | From family recollection (Andrea Restle-Lay, 2026). |
| Estimate | Worked out from the people's ages, the setting, or neighbouring photos on the same album page. Marked "c." (circa). These are the dates most worth checking. |
